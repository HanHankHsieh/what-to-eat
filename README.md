# 🎰 今天吃什麼？彈珠台抽選機

一個免安裝、純前端運作的趣味用餐抽選網頁。透過結合彈跳蘑菇頭、隨機風車與自動洗牌機制的 2D 物理彈珠台，幫你公平又充滿懸念地決定今天要吃什麼。支援電腦寬螢幕與手機直式觸控操作。

👉 **線上使用**：`https://<你的帳號>.github.io/<專案名稱>/`

---

## 🎮 基本抽選操作

1. **篩選交通方式（選用）**
   * 點擊畫面上方的交通標籤（如 `步行`、`騎車`、`開車`、`大眾運輸`、`外送`），可即時過濾本次參與抽選的候選店家。
2. **投下彈珠**
   * **隨機投球**：點擊下方的 **「投下彈珠！」** 按鈕，系統會在頂部全寬度隨機落球。
   * **手動瞄準**：直接點擊（或於手機上按住並左右滑動）彈珠台頂部區域，放開即可從指定位置投球。
3. **查看槽位與開獎結果**
   * 滑鼠移至底部槽位（或手機輕觸槽位），上方會即時顯示完整店名。
   * 彈珠落入槽位後會彈出結果視窗，可直接點擊 **「開啟導航」** 前往 Google Maps，或選擇 **「重抽一次」**（可勾選暫時排除剛剛抽到的店家）。

### 🎲 公平性與互動控制
* **抽前自動洗牌**：預設開啟。每次投球前會自動打亂底部店家的排列順序，避免物理落點偏差，確保每家店的中獎機率均等。
* **手動洗牌（🔀）**：可隨時手動重新排列底部槽位。
* **音效開關（🔊 / 🔇）**：位於右上角，可自由開啟或靜音碰撞與中獎音效。

---

## 🍽️ 店家名單管理

* **電腦版**：直接於右側面板進行管理。
* **手機版**：點擊畫面底部的 **「🍽️ 店家名單」** 分頁切換。

### 支援功能
* **新增／編輯店家**：可設定店家名稱、交通方式（支援自訂）、預估時間、Google Maps 連結與備註。
* **暫時排除開關**：若某家店今天公休或剛吃過，直接關閉該卡片的開關即可暫時移出抽籤池，無須刪除資料。
* **關鍵字搜尋**：名單較多時，可透過上方搜尋列快速尋找特定店家。
* **還原預設名單**：點擊還原按鈕可重置回內建的 23 家預設步行美食名單。

---

## 💾 資料儲存與跨裝置同步

本工具採用純前端架構，所有自訂名單皆儲存在你目前瀏覽器的 **`localStorage`** 中，不會上傳至任何伺服器。

* **注意事項**：資料綁定於單一裝置的特定瀏覽器，電腦與手機不會自動同步；若手動清除瀏覽器的「網站資料／快取」，名單將會重置。
* **備份與轉移（JSON）**：
  1. 點擊右上角 **「匯出」**，即可將目前的口袋名單下載為 `.json` 備份檔。
  2. 在另一台裝置（如手機）開啟網頁，點擊 **「匯入」** 並選擇該 `.json` 檔案，即可快速同步名單。

## 📱 手機使用小技巧

建議將網頁加入手機主畫面，獲得接近原生 App 的全螢幕體驗：
* **iOS (Safari)**：點擊下方「分享」圖示 → 選擇 **「加入主畫面」**。
* **Android (Chrome)**：點擊右上角「選單（⋮）」→ 選擇 **「加到主畫面」** 或 **「安裝應用程式」**。
