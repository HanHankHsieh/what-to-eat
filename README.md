# 🎲 今天吃什麼？多模式趣味抽選機

一個免安裝、純前端運作的響應式用餐抽選網頁。內建**彈珠台**、**雙階段拉霸機**與**俄羅斯輪盤**三種互動抽選模式，搭配瀏覽器即時合成音效與口袋名單管理，支援電腦寬螢幕與手機直式觸控操作。

👉 **線上使用**：`https://<你的帳號>.github.io/<專案名稱>/`

---

## 🎮 三大抽選模式

透過畫面上方的分頁（Tab）可隨時切換抽選方式，並可搭配交通篩選列（`🚶 步行`、`🚲 Ubike`、`🚇 捷運`、`✨ 其他`）即時過濾候選名單。

### 1. 🎰 彈珠台（Plinko）
* **操作方式**：點擊 **「投下彈珠！」** 全寬度隨機落球，或直接點擊（手機可按住左右滑動）機台頂部區域瞄準投球。
* **機台特色**：內建 12 層發光釘陣、3 顆反彈蘑菇頭、2 個每局隨機變換方向與轉速的風車，以及 4 對側壁斜角導流板。
* **公平機制**：預設開啟 **「抽前自動洗牌」**，每次投球前自動打亂底部槽位順序，確保每家店的中獎機率均等；亦可隨時點擊 **🔀 手動洗牌**。
* **槽位預覽**：滑鼠移過或手機輕觸底部槽位時，上方會即時顯示完整店名。

### 2. 🕹️ 雙階段拉霸機（Slot Machine）
* **操作方式**：點擊按鈕，或直接點擊／向下拖曳機台右側的實體拉桿啟動。
* **兩段式開獎**：左輪會先鎖定本次的 **「交通方式」**，接著右輪再從符合該交通方式的候選店家中抽出最終餐點。

### 3. 🎡 俄羅斯輪盤（Roulette）
* **操作方式**：點擊按鈕啟動立體轉盤與滾珠。
* **懸疑與翻盤機制**：滾珠初期會高速彈跳，接近結果時進入慢動作減速，並有 **50% 機率**在即將停穩的最後一刻突然「多跳一格」翻盤，大幅增加開獎驚喜感。

## 🏆 開獎結果與音效控制

* **開獎視窗**：抽出結果後可一鍵點擊 **「開啟導航」** 跳轉至 Google Maps，或選擇 **「重抽一次」**（支援勾選暫時排除剛剛抽到的店家）。
* **即時合成音效（🔊 / 🔇）**：採用瀏覽器原生 Web Audio API 即時合成各模式專屬音效（不依賴外部音檔），可透過右上角按鈕隨時切換靜音。

---

## 🍽️ 店家名單管理

* **電腦版**：直接於右側面板進行管理。
* **手機／平板版**：點擊畫面底部的 **「🍽️ 店家名單」** 分頁切換。

### 支援功能
* **內建 23 家預設名單**：初次開啟自動載入 23 家預設步行美食（附 Google Maps 搜尋導航連結），後續可自由編輯。
* **新增／編輯店家**：可自訂店名、交通方式（`步行` / `Ubike` / `捷運` / `其他`）、預估時間、Google Maps 連結與備註。
* **暫時排除開關**：公休或剛吃過的店家可直接關閉開關暫時移出抽籤池，無須刪除。
* **關鍵字搜尋與還原**：支援即時搜尋店名，並提供一鍵還原預設 23 家名單功能。

## 💾 資料儲存與跨裝置同步

本專案無後端伺服器，所有自訂名單皆儲存在目前瀏覽器的 **`localStorage`**（鍵值：`what_to_eat_plinko_v7`）中。

* **注意事項**：資料僅保留於當下使用的裝置與瀏覽器，不會跨裝置自動同步；若手動清除瀏覽器網站資料，名單將重置為預設值。
* **備份與同步（JSON）**：
  1. 點擊右上角 **「匯出」** 下載 `.json` 備份檔。
  2. 在其他裝置開啟網頁後點擊 **「匯入」** 選擇該檔案，即可完成名單轉移。
